# Руководство по привязке клавиш для  Waydroid Helper

## Обзор

Функция привязки клавиш в Waydroid Helper позволяет создавать пользовательские элементы управления клавиатурой и мышью для приложений Android, работающих в Waydroid. Эта мощная система позволяет привязать физические клавиши клавиатуры и кнопки мыши с сенсорными взаимодействиями, что делает мобильные игры и приложения более доступными на настольных системах.

## Подготовка

### Открытие интерфейса привязки клавиш

1. Запустите Waydroid Helper
2. Перейдите на вкладку **Домой**
3. В секции **Привязка клавиш** нажмите на кнопку **Открыть**
4. На вашем экране появится прозрачное окно наложения

### Понимание двух режимов

Интерфейс привязки клавиш работает в двух режимах:

- **Режим редактирования** (По-умолчанию): Используется для размещения, настройки и редактирования управляющих виджетов
- **Режим отображения**: Используется для игрового процесса с активным отображением клавиш

**Переключение между режимами**: Нажмите `F1` для переключения между Режимом редактирования и Режимом отображения.

## Настройка привязки клавиш

### Добавление виджетов

<img src="../assets/img/KEY_MAPPING/image-20250802234629279.png" alt="image-20250802234629279" style="zoom:67%;" />

1. **Убедитесть, что вы в режиме редактирования** (он открыт по умолчанию)
2. **Вторичный клик** на пустой области, чтобы открыть панель выбора виджетов
3. **Выберете тип виджета** из меню
4. **Расположите виджет**, перетащив его в нужное место на игровом интерфейсе.
5. **При необходимости измените размер** виджета выбрав его и перетаскивая границы виджета.

### Конфигурация комбинаций клавиш

1. **Двойной клик** на виджите переводит в режим захвата клавиш
2. **Нажмите необходимые клавиши,** которые вы желаете привязать к виджету
3. В виджете будет отображаться назначенная комбинация клавиш

#### Поддерживаемые типы клавиш

- **Клавиши клавиатуры**: Буквы, цифры, Fn-клавиши, модификаторы (Ctrl, Alt, Shift)
- **Кнопки мыши**: Основаная, Вторичная, Средняя
- **Комбинация клаавиш**: Одновременное нажатие нескольких клавиш (т.е., Ctrl+A, Alt+Tab)

### Продвинутая конфигурация виджетов

Многие виджеты предлагают дополнительные опции через свою панель настроек:

1. **Выберете виджет** в режиме редактирования
2. **Нажмите на значок шестерёнки** в нижнем-правом углу
3. Отрегулируйте параметры

## Использование своих привязок клавиш

### Включение привязки для игр

1. **Переключитесь на режим отображения,** нажав `F1`
2. **Расположите окно игры** под прозрачным оверлеем
3. **Используйте настроенные ваши клавиши** для управления игрой
4. Оверлей будет отображать минимальные визуальные индикаторы во время игрового процесса

### Советы по эффективному использованию

- Располагайте виджеты точно над соответствующими элементами управления
- Используйте изменения размера, чтобы выравнять размеры виджетов с игровыми элементами
- Переключайтесь обратно в режим редактирования (`F1`) в любое время, когда вам потребуется внести изменения

## Доступные виджеты управления

### 1. Одиночный клик

![image-20250802223254952](../assets/img/KEY_MAPPING/image-20250802223254952.png)

Привязывает клавишу/кнопку мыши к одному нажатию в определенном месте экрана. Срабатывает при нажатии физической кнопки и отпускается, когда она отпущена

- **Пример**: Кнопки меню, простые взаимодействия
- **Конфигурация**: Расположить виджет над целевой областью и назначить клавишу

### 2. Повторный клик

![image-20250802225228249](../assets/img/KEY_MAPPING/image-20250802225228249.png)

Автоматическое быстрое нажатие

- **Пример**: Автоатака, быстрая стрельба
- **Режим работы**:
  - **Комбо при удержании**: Непрерывные клики при удерживании клавиши
  - **Клики после нажатия**: Фиксированное количество кликов после нажатия
- **Конфигурация**: Отрегулируйте частоту и количество кликов

### 3. Прицел

![image-20250802225148255](../assets/img/KEY_MAPPING/image-20250802225148255.png)

Обычно используется в играх в жанре FPS. Добавив его в игру, можно перетаскивать точки угла обзора и взаимодействовие с кнопкой "Огонь", чтобы использовать мышь для изменения угла обзора, прицеливания и стрельбы. После добавления, пожалуйста, перетащите прямоугольное поле, чтобы отрегулировать эффективный диапазон поворота угла обзора, соответствующий эффективному диапазону, активирующий операцию изменения угла обзора в игре.

- **Использование**: Управление камерой и прицеливание
- **Особенности**:
  - Работает с кнопкой Атака для полного контроля в FPS
- **Конфигурация**: Чувствительность

### 4. Атака

![image-20250802224603813](../assets/img/KEY_MAPPING/image-20250802224603813.png)

Обычно используется в FPS играх, добавляет кнопку "Атака" для нажатия используется левая кнопка мыши и использоваться вместе с кнопкой "Прицелиться".

- **Использование**: FPS игры
- **Клавиша по-умолчанию**: Левая клавиша мыши
- **Особенности**:
  - Автоматически активируется при срабатывании виджета Прицела
  - Привязка клавиши не может быть изменена

### 5. Геймпад (Крестовина)

![image-20250802225040921](../assets/img/KEY_MAPPING/image-20250802225040921.png)

Перетащите и поместите ее на игровую крестовину перемещения, чтобы управлять направлением движения. После назначения клавиш перетащите пунктирную рамку, чтобы изменить размер кнопки; убедитесь, что синяя рамка панели управления соответствует размеру колеса в игре.

- **Использование**: Движение персонажа в играх
- **Клавиши по-умолчанию**: W (вверх), A (налево), S (вниз), D (направо)
- **Конфигурация**:
  - Режим работы:
    - **Управление движениями:** Имитирует скольжение от центра крестовины для перемещения
    - **Управление нажатиями**

### 6. Применение навыков

![image-20250802225814744](../assets/img/KEY_MAPPING/image-20250802225814744.png)

Обычно используется при использовании навыков персонажей: щелкайте мышью и взаимодействуйте с ними, чтобы активировать навыки. Перетащите пунктирную рамку, чтобы изменить размер кнопки применения навыка в соответствии с диапазоном виртуальных кнопок выбора навыка.

- **Назначение**: Продвинутое наведеине навыков на цель с помощью мыши
- **Использование**: MOBA игры
- **Конфигурация**
  - **Радиус применения:** Тонкая настройка под диапазон применения
  - **Синхронизация навыков**

    - При снятии:  нажмите и удерживаете клавишу, отпустите клавишу для применения
    - Немедленно: нажмите клавишу для применения немедленно
    - Вручную: Нажмите один раз, чтобы имитировать нажатие применения, затем нажмите кнопку еще раз, чтобы применить навык.
  - **Отмена применения:** Если включено, будет создана кнопка "отменить применение", перенесите её в положение "Отмены применения". При использовании навыка удерживайте нажатой кнопку "Отмена применения", чтобы отменить применение.

### 7. Вторичный клик для перемещения

![image-20250802231156125](../assets/img/KEY_MAPPING/image-20250802231156125.png)

Поместите его на виртуальный игровой джойстик, используя мышь для управления направлением движения и щелкните вторичной кнопкой мыши на экране, чтобы переместиться в указанное место.

- **Использование**: MOBA игры
- **Клавиша поумолчанию**: Вторичная клавиша мыши

### 8. Кнопки макросов

После добавления макрокоманды нажмите на значок шестеренки в правом нижнем углу, чтобы войти в интерфейс настроек.

- Поддерживает обычные сочетания клавиш для операций редактирования, таких как Ctrl+A (Выделить всё), Ctrl+V (Вставить), Ctrl+X (Вырезать), Ctrl+Z (Отменить), Ctrl+Y (Вернуть), etc.
- Все команды должны быть написаны строчными буквами.
- Когда вы щелкаете по экрану, координаты клика будут автоматически вставлены в текстовое поле.

#### Команда срабатывания на тайминги

**release_actions:** Каждая рабочая клавиша имеет два состояния: **нажатая (↓)** и **отпущеная (↑)**. **Состояние зажата** может быть получено, при объединении этих два состояния с соответствующими командами.

По умолчанию, при выполнении макроса команды запускаются сразу после нажатия клавиши. Если определенные команды должны запускаться при отпускании клавиши, добавьте команду **release_actions** перед этими командами.

Например:

```
# Нажать и удерживать кнопку по координатам (0,0) при нажатии клавиши макроса
# Отпустить кнопку по координате (0,0) при отпускании клавиши макроса
press 0,0
release_actions
release 0,0
```

#### Команда одиночных кликов

**click x1,y1 x2,y2...:** Click on coordinate points. Supports single-location clicks or simultaneous multi-touch by clicking multiple locations at once. Supports coordinate variables such as `mouse`.

**Note:** For single click commands, the duration from press to release is fixed.

Например:

```
# Simultaneously click coordinates (0,0), (1,1), and current mouse position
# Wait 100ms, then click (2,2)
click 0,0 1,1 mouse
sleep 100
click 2,2
```

#### Hold and Release Commands

**press x1,y1 x2,y2...:** Press and hold coordinate points. Supports holding a single position or multiple positions simultaneously.

**release x1,y1 x2,y2...:** Release the hold state of coordinate points. Supports releasing one or multiple positions.

**switch x1,y1 x2,y2...:** Toggle between [Hold] and [Release] states for specified coordinate points.

All three commands above support coordinate variables such as `mouse`.

Например:

```
# Press and hold (0,0) and (1,1) simultaneously, then release when macro key is released
press 0,0 1,1
release_actions
release 0,0 1,1

# Toggle (0,0) touch state - switches state each time the macro key is pressed
switch 0,0
```

**key_press a:** Simulate pressing a keyboard key.

**key_release a:** Simulate releasing a keyboard key.

**key_switch a:** Toggle the pressed/released state of a keyboard key.

The above three commands can call other keys nested within them (these keys must already be bound to widgets). Macro keys can also call other macro keys.

Например:

```
# Simulate pressing [A] when macro key is held, release [A] when macro key is released
key_press a
release_actions
key_release a

# Toggle [A] key state with each macro key press
key_switch a
```

#### Wait Command

**sleep duration:** Waits for a specified period of time before continuing execution.

Например:

```
# Click (0,0), wait 1 second, then click (1,1)
click 0,0
sleep 1000
click 1,1
```

#### Aim Command

Achieves a Genshin Impact PC-like effect where holding a key unlocks the mouse cursor, and releasing the key returns to locked mouse mode.

Например:

```
exit_staring
release_actions
sleep 50  
enter_staring
```

#### D-pad Radius Toggle

Allows real-time switching of d-pad radius. In games like Sky: Children of the Light and Farlight 84, this enables toggling between walk/run speeds.

**swipehold_radius x:** Adjusts the d-pad radius to x times its original size.

**swipehold_radius_switch x:** Toggles the d-pad radius between x times the original size and 1x (normal size).

Например:

```
# Walk when pressed, run when released
swipehold_radius 0.2
release_actions
swipehold_radius 1
```

```
# Toggle between walking and running with each press
swipehold_radius_switch 0.5
```
